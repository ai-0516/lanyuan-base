交互流程
主线： 微信授权登录 → 进入主页（底部 3 Tab：社交 / AI / 我的）
社交： 浏览帖子 → 内联点赞/评论/发评论 → FAB 发帖
AI： 对话历史列表 → 新对话或点击历史记录 → AI 对话界面 → 历史管理
我的： 查看资料 → 编辑资料 / 消息通知（红点可切换）→ 设置（隐私/关于/退出）

所有页面可通过上方卡片直接访问，页面内可模拟 Tab 切换和导航跳转。
