# 用户禁止行为与紧急抢修

## 禁止实施的危害供热设施安全行为

（依据《徐州市集中供热条例》第 18 条）

1. 破坏或擅自改装、拆除供热管网、标志、井盖和阀门等供热设施；
2. 破坏或擅自拆卸、改装、干扰用热计量设施；
3. 利用供热管道或支架敷设管线、悬挂物体；
4. 在供热设施安全间距范围内修建建筑物、构筑物，种植深根植物；
5. 在供热设施安全间距范围内爆破、挖坑、掘土，或打桩、顶管；
6. 在供热设施安全间距范围内堆放垃圾、杂物、易燃易爆等危险物品，排放污水、腐蚀性液体或气体；
7. 其他危害供热设施安全的行为（兜底项——危害供热设施安全但不在上列的行为同样禁止）。

## 未经供热企业同意不得妨碍供热设施正常运行的行为

（第 34 条）

1. 接入供热管道；
2. 开启入户供热阀门；
3. 改动供热管道、安装管道泵；
4. 改变用热性质和方式；
5. 排放供热系统的热水；
6. 其他妨碍供热设施正常运行的行为（兜底项——妨碍供热设施正常运行但不在上列的行为同样禁止）。

## 紧急情况入户抢修

热用户室内供热设施发生泄漏等**紧急情况**、严重影响公共安全或其他用户利益的，供热企业应当立即采取应急措施。（第 35 条）

确需入户抢修而热用户不能及时到场的：供热企业应征得热用户或其委托人**同意**，并**报告公安机关**，通知街道办事处（镇人民政府）或**物业服务人**；相关单位和个人应当配合入户抢修。（第 35 条）

## 违规后果提示

实施上述危害/妨碍行为的，供热主管部门可责令改正并罚款（单位 1 万–10 万元、个人 500–5000 元不等，视行为类型）；造成损失的依法赔偿；盗窃损毁供热设施或热力资源构成犯罪的追究刑事责任。（第 39、41、42 条）
