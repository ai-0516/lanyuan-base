AI Agent 架构 · 兰园
POST /api/v1/ai/session · POST /api/v1/ai/chat — AIAgent 自己管理 session

API 层（ai.py）

  • • POST /session → AIAgent.init_session()
  • • POST /chat → AIAgent.run(message)
  • • 不直接操作 session/DB

AIAgent（瞬态）

  • • 内部持有 session.py / context.py / streaming.py
  • • Agent Loop: while True + tool_call 检查
  • • 响应结束即销毁，无缓存

工具层 / MCP

  • • /mcp 子路由，每个 API 端点一个 tool
  • • AIAgent 调用时注入 user_id
  • • 不负责鉴权，只负责执行
