# 东方兰园地下车库平面图 — 人工矢量化需求规格书

## 一、项目概述

将东方兰园小区地下车库平面图（PNG 光栅图）人工矢量化，输出 AutoCAD DWG/DXF 文件及配套结构化数据，用于后续开发微信小程序（车位查找 + 导航）。

## 二、原始资料

- 文件：`page2_img1.png`（3370×2384 像素，地下车库平面图）
- 来源：睢宁县自然资源和规划局批前公示附件
- 内容：地下车库车位分布、墙体、柱网、道路、单元入口

## 三、矢量化要求

### 3.1 图层命名规范

| 图层名 | 内容 | 线型/颜色 |
|--------|------|-----------|
| `WALL` | 墙体（承重墙、隔墙） | 黑色实线 |
| `COLUMN` | 柱网 | 黑色矩形填充 |
| `PARKING` | 每个车位（独立闭合矩形） | 蓝色实线，线宽 0.3 |
| `ROAD` | 车道边线或中心线 | 红色虚线 |
| `ENTRANCE` | 单元门/电梯入口（点标记） | 绿色圆点 Φ200 |
| `TEXT` | 所有文字标注（编号、楼号等） | 黄色 |
| `DIMENSION` | 尺寸标注 | 灰色 |

### 3.2 车位（PARKING 层）

- **每个车位必须是独立的闭合矩形（PLINE 或 RECTANG）**
- 车位尺寸按原图比例，不得缩放
- 每个车位实体附带属性（Attribute 或 XData）：
  - `SPOT_ID`：车位编号（如 "A001"、"B102"）——按区域分段编号
  - `SPOT_TYPE`：`standard`（标准）/ `accessible`（无障碍）/ `large`（大型）

### 3.3 道路（ROAD 层）

- 绘制**车道中心线**（PLINE），标注行驶方向
- 关键节点（交叉口、转弯处）需精确
- 道路需连通到每个单元门入口

### 3.4 单元门入口（ENTRANCE 层）

- 标记每个单元门/电梯入口位置
- 附带属性：
  - `ENTRANCE_NAME`：如"3号楼1单元"、"5号楼电梯"
- 如有楼栋号标注，按原图文字录入 TEXT 层

## 四、交付物清单

### 4.1 必须交付

| # | 文件 | 格式 | 说明 |
|---|------|------|------|
| 1 | `lanyuan_parking.dwg` | AutoCAD 2018 | 完整矢量化文件，含所有图层 |
| 2 | `lanyuan_parking.dxf` | DXF R2018 | 通用交换格式 |
| 3 | `spots.csv` | CSV (UTF-8) | 车位数据表（见下方格式） |
| 4 | `roads.csv` | CSV (UTF-8) | 道路数据表 |
| 5 | `entrances.csv` | CSV (UTF-8) | 单元门入口数据表 |
| 6 | `preview.png` | PNG | 导出预览图（供确认用） |

### 4.2 CSV 数据格式

**spots.csv**（每个车位一行）：
```csv
spot_id,spot_type,center_x,center_y,width,height,rotation,nearest_road,nearest_entrance
A001,standard,12500.5,8300.2,2400,5300,0,R1,3号楼1单元
A002,standard,15000.5,8300.2,2400,5300,0,R1,3号楼1单元
```
- 坐标单位：毫米（mm），原点为图纸左下角
- rotation 为矩形旋转角度（0=水平，90=垂直）

**roads.csv**（每条道路一行，坐标序列用 JSON 数组）：
```csv
road_id,name,waypoints,connects_entrances
R1,主车道A,"[[10000,8000],[15000,8000],[20000,8200]]","3号楼1单元,3号楼2单元"
R2,B区车道,"[[20000,8200],[20000,12000]]","5号楼电梯"
```

**entrances.csv**：
```csv
entrance_id,name,x,y
E1,3号楼1单元,9800.0,7800.0
E2,3号楼2单元,9800.0,9500.0
```

## 五、质量要求

1. **坐标精度**：偏差不超过实际 50mm（CAD 图纸中 50 个单位）
2. **拓扑正确**：墙体不断线，车位不重叠，道路连通无断路
3. **车位全覆盖**：不得遗漏任何车位（原图共计约 334 个）
4. **先交付样稿**：完成 10-20 个车位 + 1 条道路的样稿，确认方向后再继续
