# 兰园社区 App — 产品需求文档 (PRD)

> **版本**: v3.0 | **状态**: 设计定稿，待开发  
> **设计稿**: `docs/design/` 目录（v3-\*.html）

---

## 1. 产品概述

### 一句话愿景
**兰园**是一个面向小区业主的轻量社区互动平台，让邻里之间能够分享生活、互通有无、互帮互助。

### 目标用户
- **小区业主/住户**：30–50 岁，关注小区生活动态、邻里社交
- **社区活跃分子**：组织活动、分享信息的关键意见领袖

### 核心解决的问题
小区业主需要一个专属的线上空间来分享生活、发现身边事、获得邻里帮助，而不是在泛社交平台中被淹没。

| 功能 | 说明 | 设计稿 |
|:---|:---|:---:|
| 编辑资料 | 头像、昵称、小区、楼号、单元、房号、个性签名 | `v3-edit-profile.html` |

| 功能 | 说明 |
|:---|:---|

## 3. 用户故事 + 验收条件

### US-01：浏览信息流
> **作为** 一位小区业主  
> **我希望** 在"发现"Tab 中看到邻居发布的帖子  
> **以便** 了解小区动态、发现身边事

**验收条件：**
- [ ] 帖子以时间倒序排列（最新在前）
- [ ] 每篇帖子包含：头像、昵称、正文、图片（可选）、发布时间
- [ ] 支持 1–9 张图片，按图片数量自动适配布局（1 张 16:9，2 张 1:1 并排，3 张上大下二，4+ 张网格）
- [ ] 点击图片打开 Lightbox 全屏预览，支持左右切换和键盘导航
- [ ] 帖子底部显示点赞用户完整名单（不缩写）
- [ ] 帖子底部显示全部评论（不折叠、不显示"查看全部"链接）

### US-02：点赞和评论互动
> **作为** 一位小区业主  
> **我希望** 对帖子点赞和评论，并能回复他人的评论  
> **以便** 与邻居互动交流

**验收条件：**
- [ ] 点击帖子右侧 `⋯` 展开操作面板，包含"点赞/取消点赞"和"评论"
- [ ] 点赞状态切换时按钮文字同步变化
- [ ] 点击"评论"从底部弹出输入浮层
- [ ] 点击任意**已有评论**，输入框 placeholder 变为 `回复 @用户名`
- [ ] 提交后评论格式为 `兰园业主 回复 老张：内容`（被回复人名字为陶土色加粗）
- [ ] 新评论追加到该帖子评论列表**最底部**
- [ ] 评论支持两级：直接评论帖子（`作者名 内容`）和回复评论（`作者名 回复 被回复人：内容`）

### US-03：消息通知
> **作为** 一位小区业主  
> **我希望** 在个人中心的"消息通知"中看到未读的互动通知  
> **以便** 及时了解谁点赞/评论/回复了我的帖子

**验收条件：**
- [ ] 个人中心"消息通知"卡片显示未读数量
- [ ] 通知页面仅显示**未读**通知，已读消失
- [ ] 每条通知格式统一：`【用户头像】用户名 点赞/评论/回复 「帖子标题」`
- [ ] 通知只有三种动作类型：点赞、评论、回复
- [ ] 不聚合：每个互动单独一条（不出现"等 N 人"）
- [ ] 未读通知有标记（淡红背景 + 右侧红点）
- [ ] 点击通知跳转到发现页并定位到对应帖子（滚动到该帖位置）
- [ ] 点击后该帖子的所有相关通知全部标记为已读

### US-04：个人资料与隐私
> **作为** 一位小区业主  
> **我希望** 在个人中心查看和编辑我的资料，并控制隐私  
> **以便** 邻居知道我住哪栋楼，同时保护具体房号隐私

**验收条件：**
- [ ] 个人中心显示头像、昵称、小区/楼号/单元/房号
- [ ] 点击"编辑资料"进入编辑页面
- [ ] 编辑资料支持：头像、昵称、小区名称、楼号、单元、房号、个性签名
- [ ] 隐私开关控制"显示我的楼号"和"显示我的房号"
- [ ] 退出登录有底部确认弹窗，防止误操作

### US-05：AI 助手对话
> **作为** 一位小区业主  
> **我希望** 在 AI Tab 中直接与助手对话  
> **以便** 快速获取社区相关信息或协助

**验收条件：**
- [ ] AI Tab 打开即显示对话界面（无历史列表）
- [ ] 输入框为 textarea，支持多行输入
- [ ] Enter 发送消息，Shift+Enter 换行
- [ ] 消息气泡：AI 为暖白背景（左下圆角 4px），用户为陶土渐变（右下圆角 4px）
- [ ] 发送后输入框自动清空并重置高度
- [ ] 消息区域可滚动，有新消息自动滚到底部

### US-06：发布帖子
> **作为** 一位小区业主  
> **我希望** 发布带图文的帖子  
> **以便** 分享小区生活、寻求帮助或组织活动

**验收条件：**
- [ ] 支持输入正文文字
- [ ] 支持上传 1–9 张图片
- [ ] 显示字数统计
- [ ] 图片可预览和删除
- [ ] 发布后跳转到发现页并显示新帖子

## 5. 数据模型建议

### User（用户）
| 字段 | 类型 | 说明 |
|:---|:---|:---|
| id | UUID | 主键 |
| nickname | String | 昵称 |
| avatar | String | 头像 URL |
| community | String | 小区名称 |
| building | String | 楼号 |
| unit | String | 单元 |
| room | String | 房号 |
| bio | String | 个性签名 |
| showBuilding | Boolean | 是否公开楼号 |
| showRoom | Boolean | 是否公开房号 |

### Post（帖子）
| 字段 | 类型 | 说明 |
|:---|:---|:---|
| id | UUID | 主键 |
| userId | UUID | 作者 |
| content | Text | 正文 |
| images | JSON/String[] | 图片 URL 列表 |
| createdAt | Timestamp | 发布时间 |

### Comment（评论）
| 字段 | 类型 | 说明 |
|:---|:---|:---|
| id | UUID | 主键 |
| postId | UUID | 所属帖子 |
| userId | UUID | 评论者 |
| parentCommentId | UUID? | 被回复的评论 ID（null = 直接评论） |
| content | Text | 评论内容 |
| createdAt | Timestamp | 评论时间 |

### Like（点赞）
| 字段 | 类型 | 说明 |
|:---|:---|:---|
| id | UUID | 主键 |
| postId | UUID | 所属帖子 |
| userId | UUID | 点赞者 |

### Notification（通知）
| 字段 | 类型 | 说明 |
|:---|:---|:---|
| id | UUID | 主键 |
| userId | UUID | 接收者 |
| type | Enum | `like` / `comment` / `reply` |
| fromUserId | UUID | 触发者 |
| postId | UUID | 关联帖子 |
| commentId | UUID? | 关联评论（可选） |
| read | Boolean | 是否已读 |
| readAt | Timestamp? | 已读时间（null = 未读） |
| createdAt | Timestamp | 通知时间 |

## 6. 非功能需求

| 类别 | 要求 |
|:---|:---|
| **响应式** | 移动端优先，以 390px 宽度为基准设计 |
| **设计语言** | 陶土暖色（`#c4673c`）+ 奶油色（`#faf7f2`）+ Deep Bark 文字 |
| **字体** | 标题 Playfair Display，正文 DM Sans |
| **导航** | 底部固定 Tab 栏，顺序：AI → 发现 → 我 |
| **滚动** | 隐藏滚动条（scrollbar-width: none） |
| **图标** | 全部使用内联 SVG，不使用 Unicode 或图片图标 |
| **头像** | 使用真实人物照片（pravatar.cc），非文字占位 |
| **图片** | 帖子图片无圆角，Lightbox 全屏预览 |
