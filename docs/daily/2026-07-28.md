## 今日成果

### 🎯 事件驱动的钩子系统（观察者模式）

**架构设计：**
```
agent.py (emit)
    ↓ 同步放到队列
asyncio.Queue
    ↓ 后台 consumer 按 Task 顺序消费
hooks/log.py（终端日志）
hooks/jsonl.py（JSONL 文件日志）
hooks/stats.py（Token 统计）
```

**8 个事件（`domain:action` 命名）：**

| 事件 | 触发时机 | 消费者 |
|------|---------|--------|
| `agent:start` | AIAgent.run() 入口 | log + jsonl + stats |
| `turn:start` | 每轮开始时 | jsonl |
| `llm:start` | LLM 调用前 | jsonl |
| `llm:end` | LLM 返回后 | log + jsonl + stats |
| `tool:start` | 每个工具执行前 | log |
| `tool:end` | 每个工具执行后 | jsonl |
| `turn:end` | 每轮结束时 | jsonl |
| `agent:end` | 循环结束 | jsonl + stats |

**事件系统演进：**
```
直接调用（第 1 版）
  → 异步 emit + 消费者（第 2 版）  
    → 统一 TypeDict 基类（最终版）
```

**关键实现细节：**
- `emit()` 是同步函数 → 放到 `asyncio.Queue` → 后台 `asyncio.Task` 顺序消费  
- 每个事件有自己的 `TypedDict` 数据类型，全部继承 `EventBase(TypedDict)` 统一 `req_id`  
- `reset()` 函数用于测试环境清理全局状态  
- uvicorn 关闭时自动取消 consumer task  
- handler 签名统一：`async def fn(data: dict)`  

### 🎯 类型安全：EventBase 统一 req_id

```python
class EventBase(TypedDict):
    req_id: str

class AgentStartData(EventBase): meta: dict
class TurnStartData(EventBase):   turn: int
class LlmStartData(EventBase):    turn, messages_sent, tools_sent
class ToolStartData(EventBase):   tool_name, tool_call_id
class ToolEndData(EventBase):     tool_name, tool_call_id, result
class AgentEndData(EventBase):    total_turns, error
```

### 🎯 _strip_avatar：统一清理头像字段

从正则替换改为**序列化前递归删除所有 dict 的 `avatar` 键**：

```python
def _strip_avatar(data) -> None:
    if isinstance(data, dict):
        data.pop("avatar", None)
        for v in data.values():
            _strip_avatar(v)
    elif isinstance(data, list):
        for item in data:
            _strip_avatar(item)
```

放在 `ToolDef.execute()` 的 `api_success` 解包后、`result_formatter` 判断前，覆盖两条路径。

## 关键决策

- **观察者模式而非插件链：** 同步 emit → 队列 → 后台 consumer，纯即发即忘不做返回值  
- **钩子是纯辅助，移除不影响核心流程：** `tool_registry.py` 不依赖事件系统，事件只在编排层 `agent.py` 发  
- **清洗/截断留在 `ToolDef.execute()` 中：** 钩子不负责修改数据，只负责记录和统计

## 经验教训

- **全局状态的测试清理很重要：** `asyncio.Queue` 是全局变量，测间共享导致 test pollution → 添加 `reset()` 函数  
- **事件名一致性降低认知负担：** `domain:action` 格式（`agent:start`, `llm:end`）比意译命名好理解  
- **TypedDict 基类比 `dict[str, Any]` 好：** 类型检查能发现问题，补全更方便  
- **不要在 tool:end 里展平或截断 result 再显示：** 原来的实现把多行展平换行符，看不出来实际大小 → 改为原始输出，只说明长度  
- **缓存命中率 95% 的观察是个惊喜：** DeepSeek 对相近 prompt 的缓存效果极好  
- **白天做功能，晚上写文档** — 今天的 40+ commits 中日志系统反复迭代了 10+ 次，文档同步写作减少后续理解成本
