## 决策记录

1. **压缩放 agent 不放 service**——service 承上启下（route 对接 + 数据准备），压缩跟随对话循环，只操作内存 messages 不碰 DB
2. **省略 s08 的 L3（tool_result_budget 磁盘持久化）**——无 read_file 大文件场景，不为不存在的场景写持久化
3. **token 用字符近似**——DeepSeek 无官方 tokenizer，`len(str(messages))` 保守偏大
4. **摘要失败容错分两级**——L4 失败跳过（reactive 兜底）；reactive 失败强裁剪兜底（保证 413 有压缩动作）
