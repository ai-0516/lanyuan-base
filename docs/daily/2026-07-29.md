## 今日成果

### 🎯 NeMo Relay 调研

调研 Hermes Agent 新集成的 NeMo Relay 可观测性方案，与我们的 replay-llm 和 hooks 系统做对比分析。

**核心发现：**
- Hermes 的 observer hooks 和我们的事件系统（`emit()` → Queue → consumer）架构方向一致
- ATIF（Agent Trajectory Interchange Format）是 NVIDIA + Harbor 联合推动的轨迹交换格式，对标我们的 replay-llm 的"导出 + 重放"能力
- Hermes 的 correlation ID 体系（`session_id → turn_id → api_request_id → tool_call_id`）比我们的更精细

**产出：** `docs/nemo-relay-vs-replay-llm.md` — 完整对比分析 + 5 条可借鉴改进点优先级排序
**Issue 追踪：** 已创建 [#2](https://github.com/snxly/lanyuan-base/issues/2) 记录 P0 改进（结构化轨迹导出）

### 🎯 事件系统升级（2 个小改动）
